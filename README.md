# OriCmd

Двухпанельный файловый менеджер для macOS в духе Total Commander.

Цель — максимально привычные для пользователей Total Commander раскладка окна,
поведение и управляющие клавиши при сохранении стандартных сочетаний macOS
(`Cmd+C`, `Cmd+V`, `Cmd+Q`, `Cmd+W`, …).

## Сборка

Требуется macOS 14+ и Xcode.

```sh
xcodebuild -project OriCmd.xcodeproj -scheme OriCmd -configuration Debug build
```
